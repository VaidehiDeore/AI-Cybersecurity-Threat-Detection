HOW TO READ THESE METRICS

Evaluation guide

Accuracy

Fraction of test examples classified correctly. It can hide poor performance on rare classes.

Precision

Of the examples assigned to a class, how many truly belonged to it.

Recall

Of the examples belonging to a class, how many the model found.

F1 score

A balance between precision and recall. Review per-class metrics as well as weighted averages.

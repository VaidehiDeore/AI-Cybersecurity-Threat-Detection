# Limitations and Responsible Use

- Synthetic data is not a substitute for evaluation on a real, representative network dataset.
- Labels describe the generator's classes; this is not a validated operational threat taxonomy.
- The severity mapping is a transparent educational rule, not a standard risk score.
- The Isolation Forest output is a separate unsupervised analysis and is not yet fused into the classifier's alert decision.
- The API is designed for local demonstration. Add authentication, rate limiting, structured logging, security review, and production server configuration before any real deployment.
- No live packet capture, exploitation, malware execution, or external target testing is performed.
